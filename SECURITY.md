# Security Policy

Please report security issues privately. Do not open public issues for vulnerabilities.

Use GitHub Security Advisories for this repository:

https://github.com/CelsianJs/vura/security/advisories/new

Include:

- affected package and version,
- reproduction steps or proof of concept,
- expected impact,
- any known mitigations.

We aim to acknowledge new reports within 3 business days, provide an initial triage update within 7 business days, and coordinate fix and disclosure timing through the private advisory thread.
