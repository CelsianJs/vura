# @celsian/then-adapter-cloudflare

Cloudflare Workers adapter for ThenJS applications.

## Install

```bash
npm install @celsian/then-adapter-cloudflare
```

## Usage

Configure in your `then.config.js`:

```js
export default {
  adapter: 'cloudflare'
}
```

Then deploy with `thenjs deploy`.
