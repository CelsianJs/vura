# @celsian/vura-adapter-cloudflare

Cloudflare Workers adapter for Vura applications.

## Install

```bash
npm install @celsian/vura-adapter-cloudflare
```

## Usage

Configure in your `vura.config.js`:

```js
export default {
  adapter: 'cloudflare'
}
```

Then deploy with `vura deploy`.
