# @celsian/then-vite-plugin

Vite plugin for Vura — enables hot module replacement, route compilation, and development tooling.

## Install

```bash
npm install @celsian/then-vite-plugin
```

## Usage

```js
// vite.config.js
import { thenPlugin } from '@celsian/then-vite-plugin'

export default {
  plugins: [thenPlugin()]
}
```
