## Sign-off

### 0.8.1 candidate — scoped agent factual review, 2026-09-06

Reviewed by the claims-audit agent against source baseline `d25a6d9` and the
documentation corrections in this change. This is an **agent review**, not a
human visual acceptance or a publication approval. Checked scope: ordinary
self-hosted versus durable task semantics, checkpoint/idempotency limitations,
implemented CLI deploy requirements, private-beta signup disclosure, adapter
middleware/action limitations, emitted artifact locations, scaffold route modes,
and dependency/CI references. Historical signoffs below remain historical.

Reproduce focused behavior checks with
`pnpm exec vitest run packages/core/test/task-steps.test.ts packages/cli/test/deploy-command.test.ts --maxWorkers=2`
and build the public content with `pnpm docs:build`. The focused tests mock the
upload adapter and exercise step replay with supplied checkpoints; they do not
prove a real managed deployment or exactly-once external effects. A repeated
`runTaskOnce` with the same run ID but no persisted steps repeats its effect,
which is why the docs require idempotency for non-idempotent writes.

Fresh Node 22.13.1 evidence for this content change: the focused suite passed
22/22 tests across two files; the TypeScript workspace build and hygiene lint
passed; the docs build emitted 33 pages. Output assertions on the create,
deploy, tasks, and adapters pages confirmed the corrected text was rendered and
the corresponding stale statements were absent. These are scoped results, not
the final whole-release gate.

The independent browser audit observed the signup page requiring a private-beta
access code; no registration was submitted. Final merged-commit CI, full-suite
counts, package sizes, packed smoke, registry publication and live admitted
signup/deploy need their own release evidence. No blanket re-verification of
every historical row or unmeasured performance claim is asserted here.
